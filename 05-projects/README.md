# 05 - Projects 🛠️

Proyectos prácticos de pequeño y mediano tamaño.

## Contenido

### small-projects/
Proyectos pequeños e integrados:
- Ejercicios prácticos que aplican múltiples conceptos
- Mini-aplicaciones
- Pequeños sistemas
- Duración: horas a pocos días

Ejemplos:
- Calculadora avanzada
- Gestor de tareas
- Sistema de puntuación
- Pequeño juego

### medium-projects/
Proyectos más complejos:
- Aplicaciones completas
- Sistemas con múltiples módulos
- Proyectos con base de datos
- APIs REST
- Duración: semanas a meses

Ejemplos:
- Aplicación web de gestión
- Sistema de blog
- Plataforma social pequeña
- Herramienta de análisis de datos

---

**Estructura sugerida para cada proyecto:**
```
small-projects/project-name/
├── README.md          # Descripción y cómo usar
├── src/              # Código fuente
├── requirements.txt  # Dependencias (si aplica)
└── docs/             # Documentación adicional
```
