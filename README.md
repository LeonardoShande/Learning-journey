# Learning Journey 🚀

Mi evolución como estudiante de Ingeniería de Software: programación, matemáticas, proyectos universitarios y experimentos.

## 📌 ¿Qué es este repositorio?

Este es mi registro técnico y académico donde documento todo mi aprendizaje en Ingeniería de Software. En lugar de fragmentar el conocimiento en múltiples repositorios, mantengo un único repositorio organizado que crece conmigo a lo largo de los años.

## 🗂️ Estructura del Repositorio

```
01-foundations/          → Conceptos fundamentales (matemáticas, lógica, algoritmos)
02-programming/          → Lenguajes de programación (Python, JavaScript, SQL, etc.)
03-university/           → Trabajos y cursos universitarios
04-experiments/          → Proyectos experimentales (IA, ciberseguridad, automatización)
05-projects/             → Pequeños y medianos proyectos
06-portfolio/            → Proyectos destacados y portafolio
```

## 📖 Documentación

Cada carpeta principal contiene un `README.md` explicando su contenido específico. Mantén esta documentación clara y concisa.

## 🛠️ Cómo Agregar Nuevo Contenido

Antes de crear archivos, determina en qué categoría encaja mejor:

1. **¿Es un concepto fundamental?** → `01-foundations/`
2. **¿Es un ejercicio de programación en un lenguaje?** → `02-programming/[lenguaje]/`
3. **¿Es una tarea universitaria?** → `03-university/[materia]/`
4. **¿Es un experimento exploratorio?** → `04-experiments/[tema]/`
5. **¿Es un proyecto pequeño o mediano?** → `05-projects/[tamaño]/`
6. **¿Es un proyecto destacado para portafolio?** → `06-portfolio/`

**Reglas de organización:**
- ✅ Usa nombres de carpetas en inglés, lowercase, con guiones
- ✅ Crea subcarpetas temáticas si es necesario
- ✅ Documenta cada carpeta con un README si contiene múltiples ejercicios
- ✅ Reutiliza categorías existentes antes de crear nuevas
- ✅ Mantén la estructura plana y fácil de navegar
