# 01 - Foundations 🏗️

Conceptos fundamentales para la programación y la ingeniería de software.

## Contenido

### mathematics/
Estudio de conceptos matemáticos esenciales:
- Álgebra lineal
- Cálculo diferencial e integral
- Ecuaciones diferenciales
- Estadística y probabilidad

### logic/
Fundamentos de lógica y teoría de conjuntos:
- Lógica proposicional
- Álgebra de Boole
- Teoría de conjuntos
- Pruebas y demostraciones matemáticas

### algorithms/
Análisis y diseño de algoritmos:
- Complejidad computacional (Big O)
- Estructuras de datos fundamentales
- Sorting y searching algorithms
- Análisis de eficiencia

### programming-basics/
Conceptos básicos de programación independientes del lenguaje:
- Variables y tipos de datos
- Control de flujo
- Funciones
- Recursión
- Paradigmas de programación

---

**Nota:** Esta carpeta es la base sobre la cual construir todas las demás. Mantener conceptos claros aquí acelera el aprendizaje en áreas superiores.
