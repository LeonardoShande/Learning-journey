# 02 - Programming 💻

Aprendizaje de lenguajes de programación y frameworks.

## Contenido

### python/
Ejercitación en Python:
- Ejercicios básicos y avanzados
- Proyectos pequeños
- Uso de librerías populares (NumPy, Pandas, etc.)
- Scripts de automatización

### javascript/
Desarrollo con JavaScript:
- Ejercicios fundamentales
- DOM y manipulación del navegador
- Async/Await y Promises
- Node.js
- Frameworks (React, Vue, etc.)

### sql/
Bases de datos y SQL:
- Queries básicas y avanzadas
- Normalización de bases de datos
- Joins y subconsultas
- Optimización de queries

### html-css/
Estructuración y estilos web:
- HTML semántico
- CSS Grid y Flexbox
- Responsive design
- Preprocesadores (SASS, LESS)

---

**Cómo agregar ejercicios:**
1. Crea una subcarpeta temática dentro del lenguaje (ej: `python/data-structures/`)
2. Organiza por dificultad o tema
3. Incluye un README si hay múltiples ejercicios relacionados
